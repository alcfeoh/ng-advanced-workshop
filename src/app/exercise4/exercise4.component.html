Exercise 4

Your mission is to implement the behavior of exercise 3 on the state dropdown

  1. If the selected country is Canada, when the user types 'Al' in the state input then only 'Alberta' should show up in the list
  2. The filter should not be case-sensitive
  3. The matching portion of the state/province name should be rendered in bold text, for instance: Alberta
  4. Use Signal Forms (form() from @angular/forms/signals and [formField]) to bind the state text input — do not use FormControl
  5. Filter the state list with a computed() signal from the Signal Form field and the states resource (no async pipe, no combineLatest / switchMap)
  6. Reuse the highlight pipe with [innerHTML] so the matching text is bold
  7. Selecting a state should be one write (selectedState). Follow that selection with linkedSignal for the filter text, and reset the chosen state when the country changes — do not use Subject or extra imperative set calls

You can take a look at the expected result here: http://localhost:4200/solution/4

Hint

The country dropdown already uses Signal Forms + computed() + linkedSignal. Apply the same pattern to the state dropdown (see solution 4).
