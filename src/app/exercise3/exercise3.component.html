Exercise 3

Your mission is to update our dropdowns so the user can type a value to filter out the dropdown contents

  1. If the user types 'Ca' then only the countries that have 'ca' in their name should show up in the list
  2. The filter should not be case-sensitive
  3. The matching portion of the country name should be rendered in bold text, for instance: Canada
  4. Use Signal Forms (form() from @angular/forms/signals and [formField]) to bind the country text input — do not use FormControl
  5. Filter the country list with a computed() signal from the Signal Form field and the countries resource — do not use toObservable or withLatestFrom
  6. Create a custom highlight pipe and bind it with [innerHTML] so the matching text is bold
  7. Load states with an httpResource whose URL/params depend on the selected country id signal. Do not worry about applying the same filter behavior to the state dropdown for now.

You can take a look at the expected result here: http://localhost:4200/solution/3
