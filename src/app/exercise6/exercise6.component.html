Exercise 6

Your mission is to create a solution that turns a clickable element into an action trigger with 3 states

  1. For instance, I could use that solution on a button with 3 possible text labels: Save, Saving..., and Saved!
  2. Pass an action (Observable or Promise) with input(). On click, run it and change the label to the working text
  3. When that action emits or resolves, change the label to the done text
  4. Keep the idle, working, and done labels customizable, and drive the host text from a signal
  5. Use a custom attribute selector so the directive is only applied when it is configured. Bind the host text and the click with the host option (host binding + host listener), not @HostBinding / @HostListener
  6. It has to work on any clickable element, not just buttons. Ignore another click while the action is still running, and do not leave a subscription behind (take(1) or firstValueFrom)

You can take a look at the expected result here: http://localhost:4200/solution/6
