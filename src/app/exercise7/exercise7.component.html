Exercise 7

Your mission is to customize the previous solution even further by being able to provide three different HTML elements for every single state

  1. For instance, I could use that solution to initially display a Save button (or any custom markup in the idle slot)
  2. Pass an action (Observable or Promise) with input(). On click, show a working slot such as the spinner assets/loader.gif
  3. When that action emits or resolves, show a done slot (for example a button that looks finished, or Done!)
  4. Project each phase with multi-slot ng-content ([default], [working], [done]) and choose the visible slot with a phase signal() (idle, working, done)
  5. Listen for the click with the component host option, not @HostListener. Ignore another click while the phase is working, and end the action with take(1) and takeUntilDestroyed
  6. It has to work on any clickable projected element, and each state should be fully customizable HTML
