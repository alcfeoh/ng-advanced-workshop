  2. Create one reusable component for that typeahead: form() from @angular/forms/signals, [formField], and a computed() filter — do not use FormControl, combineLatest, or the async pipe
  3. Then use two instances of that component, one for country selection, one for state selection. Pass the list with input() and the current choice with banana-in-a-box [(selection)] (model(), or input() plus an output() named selectionChange)
  4. Render both currently selected country and state as JSON below the dropdowns. Changing the country should clear the selected state
