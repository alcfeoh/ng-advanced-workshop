Exercise 2

Your mission is to connect the two following dropdowns so that the state/province dropdown gets populated with data from the selected country.

  1. Make sure that the state dropdown is disabled when no country is selected as well as when the selected country has no state information. Do not bind [disabled] on a [formField] select — hide it when empty, or use disabled() from @angular/forms/signals
  2. Update the code in app/exercise2 so that our component loads its list of states from http://localhost:3000/states?countryCode=US with an httpResource (or resource) whose URL/params depend on the selected country, and use the right country code as a parameter
  3. Display the total number of states (for the selected country) in the corresponding div
  4. States should be displayed in alphabetical order and using title case
  5. Selecting a state should result in the code of the state being set as the dropdown value
  6. Use Signal Forms (form() from @angular/forms/signals and [formField]) to bind both dropdowns — do not use FormControl. Read countries and states from resource signals in the template (no async pipe). Do not use switchMap, toObservable, or effect()+subscribe for this

You can take a look at the expected result here: http://localhost:4200/solution/2
